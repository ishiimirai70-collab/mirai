# 転スラ風スライムアドオン (Tensura Slime Addon) — 第一段階

Minecraft 統合版(Bedrock)用アドオン。「転生したらスライムだった件」にインスパイアされた、
**人間を取り込むことで人の姿に変身できるスライムMOB** の最初の段階を実装しています。

## 遊び方

1. `TensuraSlimeAddon.mcaddon` をタップ/ダブルクリックして Minecraft にインポートする
   (自動でビヘイビアパックとリソースパックの両方が追加されます)。
2. ワールド作成・編集画面で以下を有効にする:
   - **ビヘイビアパック**: `転スラ風スライムアドオン [BP]`
   - **リソースパック**: `転スラ風スライムアドオン [RP]`
   - 実験機能 (Experiments) の **「ベータAPI (Beta APIs)」** を ON にする
     (スクリプトAPIを使ったMOBの吸収判定に必要です)
3. ワールドに入ったら、コマンドでスライムを呼び出します:
   ```
   /summon tensura:slime
   ```
4. スライムが近くの村人 (`minecraft:villager_v2`) を攻撃して倒すと、「吸収」が発生し、
   スライムが人化能力を獲得します(専用サウンド演出付き)。
5. 吸収後のスライムを **右クリック(タップ長押し)** すると、人間の姿に変身します。
   人化形態を再度右クリックすると、スライムの姿に戻れます。何度でも往復可能です。

デバッグ用に人化形態を直接呼び出したい場合:
```
/summon tensura:human_form
```

## 収録内容

- `tensura:slime` — 見た目はスライム(オリジナルのティール色)。村人を索敵・攻撃し、
  倒すと吸収イベントが発火する。
- `tensura:human_form` — 吸収後に変身できる人間の姿(オリジナルのフード付き旅装束)。
- 吸収判定は `@minecraft/server` スクリプトAPI (`world.afterEvents.entityDie`) で実装。
- 変身は `minecraft:transformation` コンポーネントを使用し、変身後も人化能力を保持。
- 日本語 / 英語のローカライズ済み。

- 名前付け・進化(スライム→大スライム→…)要素

## 技術メモ

- `min_engine_version`: `[1, 21, 80]`
- `@minecraft/server` バージョン: `2.9.0`(安定版)
- テクスチャはオリジナルのプレースホルダーです。Blockbench 等でお好みの見た目に
  差し替え可能です(`RP/textures/entity/tensura/slime.png`,
  `RP/textures/entity/tensura/human_form.png`)。
