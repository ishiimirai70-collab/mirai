      方法1(スマホでおすすめ): 更新してMinecraftを開く

      最新の内容で .mcaddon を作り、端末の共有メニューからそのまま「Minecraft」を選んで開きます。ダウンロードフォルダを探す手間がなく、スマホでの編集→反映が一番早い方法です。 既に同じアドオンを一度インポート済みなら、Minecraft側で上書き(更新)されます。

      お使いのブラウザ/OSはファイル共有に対応していません。方法2をご利用ください。

      方法2: フォルダに直接同期 (インストールし直し不要)

      Minecraftの development_behavior_packs と development_resource_packs 内のフォルダを直接選択して、編集内容をそのまま書き込みます。 一度接続すれば、以後はこのサイトで編集して「今すぐ同期」を押すだけで反映され、ワールドを一度閉じて開き直すだけで最新の状態を確認できます(アドオンの入れ直しは不要)。
      PCのChrome/Edgeでは常に利用できます。スマホでも対応ブラウザなら使えますが、Android実機では下記の設定が必要な場合があります。

      スマホ(Android)でうまく選択できないとき Minecraftアプリの「設定 → ストレージ」にある保存先(Save Location)が「内部ストレージ(アプリ専用領域 / Android/data 配下)」になっていると、OSの制限でブラウザからそのフォルダを選べません。保存先を「内部ストレージ」以外(共有ストレージ)に切り替えると、com.mojang フォルダが通常のフォルダとして選択できるようになります。切り替えられない場合は方法1をご利用ください。
      お使いのブラウザはこの機能に対応していません。方法1または方法3をご利用ください。
