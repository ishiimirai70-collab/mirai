# 🐟 おさかな育成 〜 My Aquarium 〜

ブラウザだけで遊べる、魚を育てる箱庭ゲームです。ビルド不要、`index.html` を開くだけで遊べます。

## 遊び方

1. `fish-game/index.html` をブラウザで開く
2. 「🍞 エサをあげる」でエサをまき、魚に食べさせる
3. 満腹となかよし度が高いと魚が成長し、稚魚 → 若魚 → 成魚 → 大物 と育つ
4. 成長やエサやりで貯まったコインで、新しい魚やかざりを購入
5. 「🧽 そうじする」で水そうの汚れをリセット
6. 進行状況は5秒ごとに自動でブラウザに保存される(localStorage)

## ローカルでの起動

ファイルを直接ブラウザで開くだけで動作しますが、ローカルサーバー経由でも遊べます。

```bash
cd fish-game
python3 -m http.server 8000
# ブラウザで http://localhost:8000 を開く
```

## 構成

- `index.html` — 画面構造
- `style.css` — 見た目
- `game.js` — ゲームロジック(状態管理・アニメーション・セーブ/ロード)

外部アセットやビルドツールには依存していません。
