# 蜘蛛男風変身アドオン (Spider Hero Addon) — 第一段階

Minecraft 統合版(Bedrock)用アドオン。スパイダーマンにインスパイアされた、
**人間を噛むことで覆面ヒーローの姿に変身できる怪異グモMOB** の最初の段階を実装しています。
キャラクターデザインは既存作品のものではなく、オリジナルの配色・見た目にしています。

## 遊び方

1. `SpiderHeroAddon.mcaddon` をタップ/ダブルクリックして Minecraft にインポートする
   (自動でビヘイビアパックとリソースパックの両方が追加されます)。
2. ワールド作成・編集画面で以下を有効にする:
   - **ビヘイビアパック**: `蜘蛛男風変身アドオン [BP]`
   - **リソースパック**: `蜘蛛男風変身アドオン [RP]`
   - 実験機能 (Experiments) の **「ベータAPI (Beta APIs)」** を ON にする
     (スクリプトAPIを使ったMOBの捕食判定に必要です)
3. ワールドに入ったら、コマンドで怪異グモを呼び出します:
   ```
   /summon webhero:spider
   ```
4. 怪異グモが近くの村人 (`minecraft:villager_v2`) を攻撃して倒すと、「捕食」が発生し、
   グモがヒーロー形態への変身能力を獲得します(専用サウンド演出付き)。
5. 捕食後の怪異グモを **右クリック(タップ長押し)** すると、覆面ヒーローの姿に変身します。
   ヒーロー形態を再度右クリックすると、怪異グモの姿に戻れます。何度でも往復可能です。

デバッグ用にヒーロー形態を直接呼び出したい場合:
```
/summon webhero:hero_form
```

## 収録内容

- `webhero:spider` — 見た目は変異したクモ(オリジナルの紫黒色 + 赤い紋様)。村人を索敵・攻撃し、
  倒すと捕食イベントが発火する。
- `webhero:hero_form` — 捕食後に変身できる覆面ヒーローの姿(オリジナルの紅色マスク+紺色スーツ)。
- 捕食判定は `@minecraft/server` スクリプトAPI (`world.afterEvents.entityDie`) で実装。
- 変身は `minecraft:transformation` コンポーネントを使用し、変身後もヒーロー化能力を保持。
- 日本語 / 英語のローカライズ済み。
