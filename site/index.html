      AIアシスタント

      やりたいこと(仕様)を日本語で入力すると、Anthropic (Claude) APIを使ってスクリプトやJSONを自動生成します。APIキーはこの端末のブラウザ内にのみ保存され、Anthropicへ直接送信されます(このサイトのサーバー等は経由しません)。

      生成結果

      書き出し・同期

      方法1: .mcaddon をダウンロード (どの端末でも可)

      生成したファイル一式を1つの .mcaddon ファイルにまとめます。スマホでは、ダウンロード後にそのファイルをタップすればMinecraftにインポートできます。中身を変えるたびに再度ダウンロード＆インポートが必要です。

      方法2: フォルダに直接同期 (インストールし直し不要・対応ブラウザのみ)

      PCのChrome/Edgeでは、Minecraftの development_behavior_packs と development_resource_packs 内のフォルダを直接選択して、編集内容をそのまま書き込めます。 一度接続すれば、以後はこのサイトで編集して「今すぐ同期」を押すだけで反映され、ワールドを一度閉じて開き直すだけで最新の状態を確認できます(新しいアドオンとして入れ直す必要はありません)。
      ※ この機能はブラウザの File System Access API に対応した環境(主にPC版Chrome/Edge)でのみ使えます。スマホ(Android/iOS)はOS側の制限で対応していない場合が多く、その場合は方法1をご利用ください。

      お使いのブラウザはこの機能に対応していません。方法1(.mcaddonダウンロード)をご利用ください。
