# Mirai Addon Studio

ブラウザだけで Minecraft Bedrock Edition のアドオン(ビヘイビアパック+リソースパック)を作れるツールです。スマホでもそのまま使えます。

## できること

- **プロジェクト管理**: 複数のアドオンをブラウザ内(IndexedDB)に保存。端末を閉じても内容は残ります。
- **マニフェスト自動生成**: BP/RPの `manifest.json` をUUID込みで自動生成。
- **アイテム作成**: フォームで食べ物・道具・エンチャント・耐久値・燃料などを設定。生成されるJSONは直接編集も可能(上級者向け)。
- **ブロック作成**: 破壊時間・爆発耐性・発光・テクスチャなどをフォームで設定。
- **スクリプト(Script API)**: `@minecraft/server` を使ったコードをテンプレートから挿入、または自由に編集。
- **AIアシスタント**: やりたいことを日本語で入力すると、Anthropic (Claude) API が該当するスクリプト/JSONをその場で生成します。APIキーは端末のブラウザ内にのみ保存され、Anthropicへ直接送信されます(このサイト運営者のサーバーは経由しません)。
- **スマホでの更新・反映(方法1)**: 「更新してMinecraftを開く」を押すと最新版の `.mcaddon` を作り、OSの共有シートからそのまま「Minecraft」を選んで開けます(Web Share API)。ダウンロードフォルダを探す手間がなく、パックバージョンも書き出しのたびに自動で1つ上がるので、Minecraft側で正しく更新扱いになります。
- **フォルダ同期(方法2)**: 対応ブラウザでは、Minecraftの `development_behavior_packs` / `development_resource_packs` 内のフォルダに直接書き込めます。一度接続すれば、以後は編集→同期→ワールドを開き直すだけで反映され、毎回アドオンを入れ直す必要がありません。PCのChrome/Edgeでは常時利用可能。Androidでは、Minecraft側の「設定→ストレージ」の保存先がアプリ専用領域(Android/data配下)のままだとOSの制限で選択できないため、共有ストレージに切り替える必要がある場合があります(アプリ内に手順を表示しています)。
- **書き出し(方法3)**: `.mcaddon` ファイルとしてダウンロード(どの端末でも可能な最終手段)。

## 使い方(ローカルで開く場合)

このディレクトリを任意の静的ファイルサーバーで配信するだけです。例:

```
cd site
python3 -m http.server 8080
```

ブラウザで `http://localhost:8080` を開いてください。

## GitHub Pages で公開する場合

リポジトリの Settings → Pages で、公開元をこの `site/` ディレクトリ (またはこの内容をルートに配置したブランチ)に設定してください。公開後はスマホのブラウザからそのURLを開くだけで使えます。

## 注意事項

- 「更新してMinecraftを開く」(方法1)はWeb Share APIを使うため、HTTPS配信かつ対応ブラウザ(Android Chromeなど)が必要です。対応していない場合は自動で警告を表示し、方法3(ダウンロード)を案内します。
- フォルダ同期(方法2, File System Access API)はPCのChrome/Edgeで確実に使えます。スマホでも対応ブラウザなら使えますが、AndroidのOS制限により、Minecraft側の保存先設定を共有ストレージに変更しないと対象フォルダを選べない場合があります。
- AIアシスタントの利用には、ご自身のAnthropic APIキーが必要です。生成されたコードは必ず内容を確認してから反映してください。
