# Mirai Addon Studio

ブラウザだけで Minecraft Bedrock Edition のアドオン(ビヘイビアパック+リソースパック)を作れるツールです。スマホでもそのまま使えます。

## できること

- **プロジェクト管理**: 複数のアドオンをブラウザ内(IndexedDB)に保存。端末を閉じても内容は残ります。
- **マニフェスト自動生成**: BP/RPの `manifest.json` をUUID込みで自動生成。
- **アイテム作成**: フォームで食べ物・道具・エンチャント・耐久値・燃料などを設定。生成されるJSONは直接編集も可能(上級者向け)。
- **ブロック作成**: 破壊時間・爆発耐性・発光・テクスチャなどをフォームで設定。
- **スクリプト(Script API)**: `@minecraft/server` を使ったコードをテンプレートから挿入、または自由に編集。
- **AIアシスタント**: やりたいことを日本語で入力すると、Anthropic (Claude) API が該当するスクリプト/JSONをその場で生成します。APIキーは端末のブラウザ内にのみ保存され、Anthropicへ直接送信されます(このサイト運営者のサーバーは経由しません)。
- **書き出し**: `.mcaddon` ファイルとしてダウンロード(どの端末でもインポート可能)。
- **フォルダ同期**: 対応ブラウザ(PCのChrome/Edgeなど)では、Minecraftの `development_behavior_packs` / `development_resource_packs` 内のフォルダに直接書き込めます。一度接続すれば、以後は編集→同期→ワールドを開き直すだけで反映され、毎回アドオンを入れ直す必要がありません。

## 使い方(ローカルで開く場合)

このディレクトリを任意の静的ファイルサーバーで配信するだけです。例:

```
cd site
python3 -m http.server 8080
```

ブラウザで `http://localhost:8080` を開いてください。

## GitHub Pages で公開する場合

リポジトリの Settings → Pages で、公開元をこの `site/` ディレクトリ (またはこの内容をルートに配置したブランチ)に設定してください。公開後はスマホのブラウザからそのURLを開くだけで使えます。

## 注意事項

- フォルダ同期機能(File System Access API)はChromium系ブラウザ(PC版Chrome/Edge)向けです。スマホ(特にAndroid/iOS)はOSの制限により対応していないことが多いため、その場合は `.mcaddon` のダウンロード&インポートをご利用ください。
- AIアシスタントの利用には、ご自身のAnthropic APIキーが必要です。生成されたコードは必ず内容を確認してから反映してください。
