# マイクラ アドオンメーカー (Minecraft Addon Maker)

ブラウザだけで Minecraft 統合版 (Bedrock Edition) のアドオン (`.mcaddon`) を作成できる、
インストール不要の Web ツールです。サーバーは使わず、すべての処理はブラウザ内で完結します。

## できること

- アドオンの基本情報(名前・識別子・説明・アイコン)の設定
- オリジナルアイテムの作成(通常アイテム / 食べ物 / 道具・武器)
- オリジナルブロックの作成(テクスチャ・硬さ・爆破耐性など)
- クラフトレシピの作成(3x3の型あり、または材料だけの型なし)
- 完成したアドオンを `.mcaddon` ファイルとしてダウンロード
  (タップ/ダブルクリックでビヘイビアパック・リソースパックの両方がMinecraftにインポートされます)
- 入力内容はブラウザの `localStorage` に自動保存されるので、途中で閉じても続きから作成できます

## 使い方

1. `index.html` を開く(ローカルで確認する場合は、下記のように簡易サーバーを立てて開いてください)。
2. 「基本情報」タブでアドオン名・識別子などを入力。
3. 「アイテム」「ブロック」「レシピ」タブで作りたい要素を追加。
4. 「プレビュー / 書き出し」タブ、またはヘッダーの「.mcaddon をダウンロード」ボタンから書き出す。
5. ダウンロードしたファイルをスマホ/PCでタップまたはダブルクリックしてMinecraftにインポート。

### ローカルでの確認方法

```bash
cd website
python3 -m http.server 8000
# ブラウザで http://localhost:8000 を開く
```

`file://` で直接開いても動作しますが、ブラウザによっては制限があるため簡易サーバー経由を推奨します。

## 技術メモ

- フレームワーク不使用のプレーンな HTML / CSS / JavaScript。ビルド不要。
- ZIP (`.mcaddon`) の生成には [JSZip](https://stuk.github.io/jszip/) を使用 (`vendor/jszip.min.js` に同梱、外部CDN不要)。
- 生成するアイテム/ブロック/レシピの JSON は Bedrock のレガシー安定フォーマット (`format_version: 1.16.100`) を使用しており、
  幅広いバージョンの Minecraft 統合版で動作します。
- テクスチャ未指定のアイテム/ブロックには、IDから自動生成したプレースホルダー画像が使われます。
- アイコン未設定のアドオンにも、自動生成したアイコン画像が使われます。

## 制限事項 (今後の拡張候補)

- カスタムエンティティ(MOB)の作成には対応していません(モデル/アニメーション作成が必要なため)。
- アイテムの道具コンポーネントは簡易版(耐久値・攻撃力のみ)です。
- ディメンションの追加には対応していません。
