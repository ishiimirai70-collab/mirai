# 🎣 つりずかん

3D の釣り × すいぞくかんゲーム。ブラウザだけで遊べます。`index.html` を開くだけで起動し、Three.js は CDN (jsdelivr) から読み込みます(要インターネット接続)。

`../fish-game/` にあった「コインで魚を買う」旧バージョンから、「釣って集める」方式に作り直したものです。

## 遊び方

1. 🎣 つり場でキャストし、魚のあたりを待つ
2. ❗ が出たら素早く「あわせる」をタップ
3. 表示されるメーターが満タンになるまで「まきとる」を押しっぱなしにする(魚が引くと減るので離さないこと)
4. 釣れた魚はレアリティ(コモン〜伝説)と一緒にカードで表示され、🐠 すいぞくかんに自動で泳ぎに行く
5. 📖 図鑑で発見した魚のコレクションを確認できる

## ローカルでの起動

```bash
cd fish-game-3d
python3 -m http.server 8000
# ブラウザで http://localhost:8000 を開く
```

## 構成

- `index.html` — HTML / CSS / ゲームロジックをまとめた単一ファイル(Three.js のみ外部 CDN 読み込み)

外部依存は Three.js (CDN) と Google Fonts のみで、ビルドツールは使用していません。
